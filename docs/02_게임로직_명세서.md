# 사사끼 게임 로직 명세서

## 원칙
- **서버 권위형(authoritative)**: 손패, 카드 사용, 타이머, 특수 행동, 정산은 서버가 유일한 진실의 원천.
- 모든 명령은 `gameId`, `playerId`, `actionId`, `expectedRevision` 포함. 서버는 중복 `actionId`를 재실행하지 않고, 상태 리비전이 오래된 명령을 거절/재검증.
- 카드의 고유 ID는 무늬+숫자. 사용된 카드는 다시 손패에 들어오지 않음(무르기 반환 제외). 전체 카드 48장 불변식 유지.
- 서버 이벤트 로그로 카드 제출, 패스, 특수 행동, 완주 확정/취소, 알 이동을 추적.

## 권장 상태
```ts
type Phase = 'lobby'|'deal'|'run-declare'|'ddook-declare'|'turn'|'special-response'|'trick-clear'|'settlement'|'hand-result'|'paused'|'match-end';
type PlayerState = { id:string; seat:0|1|2|3; nickname:string; hand:CardId[]; eggs:number; finishRank?:1|2|3|4; completedCareHand:boolean; connection:'online'|'ai'; reconnectTokenHash:string };
type GameState = { id:string; revision:number; phase:Phase; players:PlayerState[]; activeSeat?:number; leaderSeat?:number; lastAttack?:Attack; trick:Attack[]; pendingSpecial?:PendingSpecial; finishedSeats:number[]; teamMode:'fire-2v2'|'pig-1v3'; fireOwners:number[]; runDeclared:boolean; ddookDeclared:boolean; multiplier:1|2|4; buriedEggs:number; careRecipient?:number; turnDeadline?:number; roomExpiry?:number };
```

## 상태 전이
1. 로비: 4명 준비, 시작 알 수 설정.
2. 분배: 48장 섞어 각 12장, 첫 판 돼지이면 다시 섞기. 선 선정.
3. 달리기 5초 → (달리기 발생 시) 뚝 5초 → 턴 시작.
4. 턴: 제출/패스/시간 초과. 카드 제출은 합법 조합 판정, 공격 비교, 특수 반응 가능 여부를 평가.
5. 특수 반응: 찼다·무르기·꽂다·흑돼지. 필요시 5초 결정. 반응 확정 시 기존 턴/선 재설정.
6. 나머지 모두 패스: 트릭 정리 → 마지막 공격자 선, 완주했다면 통선.
7. 세 번째 완주 확정: 네 번째 자동 결정 → 정산 → 배려판/탈락/다음 판.
8. 모두 오프라인: 일시정지/시계 잔여 보존. 1명 복귀 시 재개. 1시간 만료 시 폐기.

## 합법성 검사
- 손패에 해당 카드가 실제 존재하는지 확인.
- 일반 제출: `classifyCombo(cards)` → `canBeat(newCombo, currentAttack)`.
- 닐리리/쌍카는 동일 장수/쌍수 및 최상위 숫자로 비교.
- 찼다: 현재 대상 싱글과 같은 숫자 페어, 또는 지정된 4-5-6 닐리리와 44-55-66.
- 꽂다: 찼다 후 남은 해당 숫자 싱글(쌍카 찼다라면 4,5,6 각 한 장).
- 무르기: 직전 대상 싱글 뒤 정확히 한 장이 추가로 나온 경우, 대상 숫자 페어 보유, 후속 카드 반환. 세 번째 행동 확정 이후 불가.
- 불돼지: 흑돼지 외 다른 대응 불가. 흑돼지 보유자에게 5초 선택, 만료 시 통과.
- 완주: 무르기 반환 가능성 있으면 잠정; 최종 확정 이후에만 순위 부여. 단 찼다·꽂다·흑돼지 대응은 확정 순위를 변경하지 않음.

## 동시성
- 서버는 행동을 단일 직렬화 큐로 처리. 같은 처리 배치의 무르기/찼다 충돌 시 무르기 우선.
- 한 번 확정된 찼다는 늦은 무르기로 되돌리지 않음.
- 자동 행동과 사람의 복귀가 겹치면 서버 확정 순서 기준. 복귀 후 미확정 AI 행동 취소.
- 8초 턴/5초 특수 창은 서버 시간 기준. UI 애니메이션과 효과음은 게임 상태를 임의 변경하지 않음.

## 알 정산 함수
- `computeBaseTransfer(mode, ranks, multiplier)`는 지급 의무를 먼저 계산.
- `settle2v2`는 양쪽 승자에게 동일 지급액을 보장하고 초과 납부 가능분은 buried로 이전.
- `settlePigWin`은 흑팀 개별 지급액을 돼지에게 이전, 미지급 부족분은 소멸, 기존 buried 전액 돼지에게 지급.
- `settlePigLose`는 돼지 보유액을 세 명에게 균등 지급, 나머지 buried.
- 정산 후 `exactZero`와 `insufficientFunds`를 구분하고 배려판 이력/동시 대상자 수를 평가.
- 알 보존 불변식: 각 플레이어 알 총합 + buried는 정산 전후 동일(외부에서 알 생성·소멸 없음). **단 부족분은 실제 지급 의무만 소멸하며 존재하지 않는 알을 차감하지 않음.**

## 개발 주의
- 카드 조합 전체 우선순위, 배려판 실패의 정확한 판정 등은 `06_미확정_사항.md`를 먼저 확인.
- 클라이언트는 다른 사람의 손패 및 숨겨진 팀 정보를 받지 않도록 플레이어별 공개 상태를 별도로 구성.
- 임시 복귀 토큰은 난수로 생성, 서버에는 해시만 저장, HTTPS/안전한 쿠키 등 적절한 보안 적용.
