# 사사끼 기술 설계서 (권장안)

## 기술 선택
- **TypeScript** 단일 언어.
- 프런트엔드: React + Vite (모바일/데스크톱 반응형).
- 서버: Node.js + TypeScript + Socket.IO 또는 동등한 WebSocket 솔루션.
- 게임 규칙: 서버와 테스트에서 공유하는 순수 함수 모듈(`packages/game-core`). 클라이언트가 판정의 최종 권한을 갖지 않음.
- 초기 저장: 개발용 메모리 상태 + 테스트. 이후 방 상태 스냅샷을 Redis/DB 등에 보존. 1시간 일시정지 복구를 위해 서버 재시작에도 유지할지 결정해야 함.
- 테스트: Vitest 단위/속성 테스트, Playwright 브라우저 E2E.
- 배포: HTTPS 및 WebSocket 지원 호스팅. 실제 서비스 전 비용·동시접속 한도 검토.

## 추천 디렉터리
```text
sasaki/
  apps/web/           # 브라우저 UI
  apps/server/        # 방/실시간 통신/서버 판정
  packages/game-core/ # 카드·조합·턴·정산 순수 로직
  tests/scenarios/    # 규칙 시나리오
  docs/               # 이 패키지의 명세서
```

## 주요 화면
1. 로비: 방 만들기/참가, 닉네임, 초기 알, 4인 대기.
2. 게임판: 4개 좌석, 중앙 카드 더미, 현재 선/턴, 본인 손패, 선택·제출·패스, 특수 버튼, 묻어둔 알.
3. 달리기/뚝 선언: 5초 선택 창.
4. 판 결과: 순위·팀·이번 판 증감·누적 알·다음 판.
5. 최종 결과: 탈락 시 종료, 잔액 기준 공동 순위.
6. 연결 복구: AI 대리 플레이 상태, 자동 재접속, 전원 퇴장 시 일시정지.

## 실시간 메시지 예시
- 클라이언트→서버: `joinRoom`, `playCards`, `pass`, `declareRun`, `declareDdook`, `chatda`, `kkotda`, `mureugi`, `blackPigSubmit`, `blackPigPass`, `reorderCards`(로컬 우선), `leaveRoom`.
- 서버→클라이언트: `roomSnapshot`, `statePatch`, `actionRejected`, `turnStarted`, `specialWindowOpened`, `handSettled`, `matchEnded`, `connectionStatus`.
- 카드 제출과 특수 행동은 중복 방지 ID 필수. 서버 시간/리비전 동기화.

## 구현 마일스톤
- M1: 카드/조합/턴/순위/정산 테스트. 콘솔 시뮬레이터.
- M2: 한 브라우저에서 네 좌석을 제어하는 로컬 프로토타입.
- M3: 실시간 4인 방, 손패 비공개, 타이머, 특수 행동.
- M4: AI 대리 플레이, 자동 재접속, 1시간 방 보존.
- M5: 애니메이션·효과음·모바일 조작·배포.

## 품질 게이트
각 마일스톤 완료 시 자동 테스트 통과, 시연 가능 URL 또는 로컬 실행 명령, 알려진 문제 목록, 변경된 명세서 동기화.
