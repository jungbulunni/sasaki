1. 이 ZIP 파일을 압축 해제하고 프로젝트 폴더를 만듭니다.
2. Claude Code에서 해당 폴더를 열고 `05_Claude_개발지시서.md`의 첫 프롬프트를 전달합니다.
3. 1차 목표는 **브라우저에서 한 명이 네 자리를 테스트할 수 있는 기능성 프로토타입**입니다. 그래픽과 음향은 뒤로 미룹니다.
4. 자동 테스트를 통과한 뒤 실시간 멀티플레이, 접속 복구, AI 대리 플레이를 차례로 추가합니다.
5. `06_미확정_사항.md`에 적힌 개발 차단 이슈는 코드로 임의 결정하지 말고 사용자에게 한 번에 확인받습니다.
