# 사사끼를 인터넷에 올리기 (Render 무료)

## 준비물
- GitHub 계정 (코드를 보관하는 곳) — github.com
- Render 계정 (서버를 켜두는 곳) — render.com, GitHub 계정으로 가입 가능
- `sasaki-M3.zip` (압축 풀어서 사용)

## 1. GitHub에 코드 올리기
1. github.com 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름 `sasaki`, 공개 여부는 **Private** 추천 → **Create repository**
3. 새 저장소 화면의 **uploading an existing file** 링크 클릭
4. `sasaki-M3.zip`을 풀어서 나온 `sasaki` 폴더 **안의 내용물 전부**를 끌어다 놓기 (폴더째가 아니라 안의 파일·폴더들)
5. 아래 **Commit changes** 클릭

## 2. Render에서 서버 켜기
1. render.com → **GitHub로 가입/로그인** → GitHub 저장소 접근 허용
2. 대시보드 **New +** → **Blueprint** → `sasaki` 저장소 선택
3. 설정(render.yaml)이 자동으로 읽힘 → **Apply**
   - 수동으로 할 때: New + → Web Service → 저장소 선택 → Build Command `npm install && npm run build`, Start Command `npm start`, Instance Type **Free**
4. 몇 분 뒤 `https://sasaki-xxxx.onrender.com` 같은 주소가 생기면 완료

## 3. 친구들과 하기
1. 주소를 열고 닉네임 입력 → **방 만들기**
2. 대기실의 **링크 복사** → 친구 세 명에게 전송
3. 4명이 모이면 방장이 **게임 시작**

## 무료 요금제에서 알아둘 점
- 15분 동안 아무도 접속하지 않으면 서버가 잠듦. 다음에 처음 열 때 깨어나는 데 1분 정도 걸림.
- 게임 중(카드를 주고받는 동안)에는 잠들지 않음.
- 서버가 다시 시작되면(코드 업데이트 등) 진행 중인 방은 사라짐. 시험판 단계에서는 이렇게 두기로 함.
- 한 달에 무료 750시간. 친구들끼리 쓰기에는 충분.
