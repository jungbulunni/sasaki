# Claude Code 개발 지시서

## 첫 번째로 전달할 프롬프트 (그대로 복사)

```text
당신은 숙련된 TypeScript 풀스택 게임 개발자이자 QA 엔지니어입니다.
이 폴더의 docs/00~06 문서를 모두 읽고, '사사끼' 4인 실시간 웹 카드게임을 단계적으로 개발하세요.

최우선 원칙:
1. 01_사사끼_공식규칙서.md를 게임 규칙의 기준으로 삼습니다.
2. 06_미확정_사항.md에 적힌 불명확한 규칙을 임의로 만들어 구현하지 마세요. 개발을 막는 항목만 한 번에 묶어 질문하세요.
3. 서버 권위형 게임 상태를 사용하고 카드/조합/점수 판정은 순수 함수로 구현하세요.
4. 한 번에 전체 서비스를 완성하려 하지 말고 M1 → M2 → M3 → M4 → M5 순서로 진행하세요.
5. 우선 M1을 시작하세요: 프로젝트 구조, 카드 모델, 조합 판정, 턴 엔진, 정산 엔진, 단위 테스트를 구현하고 테스트를 실행하세요.
6. 구현 후 실행 명령, 통과한 테스트, 아직 미구현인 기능, 확인이 필요한 규칙을 한국어로 보고하세요.
7. 구현 전에 간단한 작업 계획을 제시하고, 각 단계마다 실제 파일을 만들고 테스트하세요.
```

## M1 이후 요청 예시
- `M1 테스트가 통과했다면 M2를 진행해 주세요. 한 브라우저에서 네 좌석을 전환하며 전체 판을 테스트할 수 있게 만들어 주세요.`
- `M2가 통과했다면 M3를 진행해 주세요. 각 플레이어는 자신의 손패만 보도록 하고, WebSocket으로 상태를 동기화해 주세요.`
- `M3가 통과했다면 M4를 진행해 주세요. AI 대리 플레이와 동일 브라우저 자동 복귀를 구현하고 중복 제출 경합 테스트를 추가해 주세요.`
- `M4가 통과했다면 M5를 진행해 주세요. 카드 선택·드래그, 효과음, 결과 화면을 다듬어 주세요.`

## 개발자가 확인할 산출물
- 실행 가능한 소스코드 및 README
- 테스트 실행 명령과 통과 결과
- 로컬에서 4인 테스트하는 방법
- 미확정 규칙을 사용자에게 질문한 기록
- 실제 게임 플레이 영상 또는 스크린샷(가능한 경우)

## 주의
Claude Code는 설치/로그인 및 사용 가능한 구독 또는 별도 사용량 결제가 필요할 수 있습니다. 현재 요금·플랜·설치법은 공식 안내에서 확인하세요.
